# Fotos de stock (temporales)

por ser de patín carrera / speed skating y tener sentido temático con el sitio mientras no estén las
fotos reales del cliente. **Reemplazar por material real de MC Cargo antes de publicar** (ver
`docs/specs/002-hero.md`, `003-nosotros.md` y `004-productos-home.md` → "Abierto/pendiente").
